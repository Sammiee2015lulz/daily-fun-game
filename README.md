# Daily Fun Game 🎮

Everyday a fun and cool game, hosted here on GitHub!

## Today's Game: Orb Catcher

Catch the glowing orbs with your paddle, avoid the bombs!

### How to Play
1. Open `index.html` in your browser (or enable GitHub Pages for this repo).
2. Move with mouse or Left/Right arrow keys.
3. Catch green orbs for points (+10), avoid red bombs (lose a life).
4. Survive as long as you can – speed increases!

High score is saved locally in your browser.
