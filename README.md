# Daily Fun Game 🎮

Everyday a fun and cool game, hosted here on GitHub!

## Today's Game: Neon Jumper

Jump over spikes and collect stars in this neon endless runner!

### How to Play
1. Open `index.html` in your browser (or enable GitHub Pages for this repo).
2. Press Space, Click, or Tap to Jump.
3. Avoid the purple spikes, collect yellow stars for bonus points.
4. Score increases automatically – speed ramps up!

High score is saved locally in your browser.
